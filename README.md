# A7 Training

Marketing website for **A7 Training** — personal training, strength & conditioning, and online coaching.

A single-page, fully responsive site (phone / tablet / desktop) with a liquid-glass UI, built around the A7 barbell logo in the brand's gold-on-forest-green palette.

## Live site

Hosted with GitHub Pages. Once enabled (**Settings → Pages → Deploy from branch → `main` / root**), the site is available at:

`https://alexappemail1234567-oss.github.io/Trainingapp/`

## Structure

- `index.html` — the entire site (self-contained: HTML, CSS and a little JS, no build step).
- `photos/` — add your images here (see the placeholders on the page for recommended sizes).
- `videos/` — add short clips here (MP4, ~1080p, compressed).

## Editing

Open `index.html` in any browser to preview locally. Swap the dashed placeholder blocks for real `<img>` / `<video>` tags pointing at files in `photos/` and `videos/`.
